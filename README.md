# Bazar-Dor 🛍️

Bazar-Dor is a modern online marketplace built with Next.js. Users can browse products, explore categories, view product details, and manage their profiles.

## Features

- Responsive marketplace homepage
- Product browsing and category-based navigation
- Product details pages
- Product sorting and promotional marquee
- User authentication with Better Auth
- Google and GitHub authentication support
- User profile and profile update pages
- Loading states and custom 404 page
- Responsive navigation and reusable UI components

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Better Auth
- MongoDB

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/biddut-webdev/Bazar-Dor.git
cd Bazar-Dor
```

### 2. Install dependencies

```bash
npm install
```

### 3. Configure environment variables

Create a `.env` file in the project root and add the environment variables required by your Better Auth and MongoDB configuration.

Do not commit your `.env` file or expose secret keys.

### 4. Run the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build for Production

```bash
npm run build
npm start
```

## Deployment

The application can be deployed on [Vercel](https://vercel.com/).
